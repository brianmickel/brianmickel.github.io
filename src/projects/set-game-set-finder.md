summary: A Python CLI that tells you whether a set is on the table, without telling you which.
---

Cards go in a text file as four-character codes, one per line (`ps3l`: purple, squiggle, three, striped). The script reports "Set(s) Found" or "No Sets Found" and deliberately stops there, so you can keep looking.

The readme from 2018 sketched four stages: a CLI, a web version, image upload, and eventually a phone pointed at the table like a bank check deposit. [Set Check](/projects/set-check/), seven years later, is stage three.
