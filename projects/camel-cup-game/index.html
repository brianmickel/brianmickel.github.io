Camel Up odds

2017-01-23 ProjectsBoard gamesRepository

An object model of the board game, with a pie chart of each leg's likely outcomes.

A Python representation of Camel Up's board and dice, run forward many times to estimate who wins the current leg. The output is a matplotlib pie chart of the probabilities, which is what you actually want to know when you're deciding whether to bet.
